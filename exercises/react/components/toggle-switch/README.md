# Toggle Switch

## Task
Create a `ToggleSwitch` component that allows users to toggle between two states: "ON" and "OFF".

### Requirements:
1.  The component should display a button or a switch-like element.
2.  The initial state should be "OFF".
3.  Clicking the switch should toggle its state.
4.  The current state ("ON" or "OFF") should be visible to the user.
5.  The component should accept an optional `onToggle` callback prop that is called with the new state whenever it changes.

### Bonus:
-   Style it to look like a real switch.
-   Add accessibility (ARIA roles/labels).
