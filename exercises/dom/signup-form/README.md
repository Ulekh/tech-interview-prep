# signup-form

## Task
Implement the DOM manipulation component/widget for **SignupForm**.

### Files:
- `index.html`: HTML markup and structure.
- `index.ts`: Interactivity, event listeners, and DOM updates.
- `style.css`: Component styling.

### Requirements:
1. Add the required HTML structure in `index.html`.
2. Handle user interactions and update the DOM in `index.ts`.
3. Clean up any timers or event listeners if necessary.

### Preview & Testing
- **Interactive Preview**: Run `npm run dev` and open `http://localhost:5173/?category=dom&name=signup-form`.
- **Run Tests**: `npx vitest exercises/dom/signup-form`.
